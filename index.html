Review gatherings found in the newspapers

  1. Download an export file from the elsa releases page (you need to be logged in to GitHub). Smaller files, such as one newspaper or one decade, open fastest.
  2. Open it here. The file stays on your computer. Large files can take a minute or two, so please be patient.
  3. Browse and report. When something is wrong, press Report a problem and say what is wrong in a few words.
  4. Send your reports. Press My reports, then Send to GitHub. GitHub opens; log in if asked and follow the steps there. A colleague reviews your reports before they are used.

    Choose a gathering from the list to see the newspaper reports behind it.

    My reports

      Send to GitHub opens GitHub in a new tab with your reports filled in.

      1. Log in to GitHub if asked.
      2. Press the green Commit changes… button, then Propose changes.
      3. On the next page press Create pull request.

      A colleague then reviews your reports.

      You can also download your reports as a file and e-mail it to the project instead.
